# 画面文言の編集方法

編集するファイルは `src/content/ja.json` です。JSONは、項目名と内容を対にして書くテキスト形式です。アプリの処理やHTMLを書き換える必要はありません。

## よく使う項目

| 項目名 | 表示場所 |
| --- | --- |
| `app.title` / `app.brand` | 画面のタイトル、ブラウザタブのタイトル、英字名 |
| `button.check` / `button.checkAi` / `button.checking` | 形式チェック、AIチェック、実行中のボタン |
| `view.edit` / `view.review` / `view.hint` | 左パネルの表示切替と説明 |
| `privacy.*` | 情報の取り扱いの説明 |
| `help.*` | 右上の使い方ウインドウ |
| `check.*` / `ai.*` | チェック・AIの進捗とエラー |
| `candidate.*` / `column.*` | 候補表の通知・見出し |
| `copy.*` / `mapping.*` / `output.*` | コピー・保存の通知 |
| `file.mapping` / `file.output` | CSV・TXTの保存ファイル名 |
| `categories` 内の `PERSON`、`ORG` など | 画面上の日本語種別名 |

`*` は「同じ始まりの項目全般」という意味で、実際の項目名には含めません。

## 編集例

```json
"button.check": "形式でチェック"
```

左の項目名は変えず、右の内容を編集します。ダブルクォート `"` と行末のカンマの配置を保ってください。本文中にダブルクォートを書きたい場合は `\"` とします。改行は `\n` と書けますが、表示場所によっては空白として表示されます。

`{count}`、`{percent}`、`{text}` などは、件数や進捗を自動挿入する目印です。削除・改名せず、周りの文章を編集してください。HTMLのタグは使用できません。`<` や `"` は文字として安全に表示されます。

種別の `ORG` などの項目名は処理上の識別子です。変更するのは右側の日本語名だけです。画面の種別名を変えても `<ORG_01>` やCSV内の `ORG` は変わりません。`column.original`、`column.replacement`、`column.category`、`column.count` はCSVの見出しにも使います。

保存ファイル名を変更する場合は `.csv` / `.txt` を残してください。パスの区切り文字（`/` や `\`）は使わないでください。

## 反映

1. JSONを編集して保存します。
2. `npm test` と `npm run build` を実行し、エラーがないことを確認します。
3. `npm run dev` で表示を確認するか、更新したコードからCIを新規実行して配信先へ配置します。

文言はビルド時に同梱されるため、設定を読むための外部通信は増えません。ダウンロード済みの古いCI成果物には変更が反映されません。

## 開発者向け

- `src/content/text.ts`：項目の取得・値の差し込み・HTML用の文字エスケープ。
- `src/ui/template.ts`：画面構造。表示文字列は `htmlText()` でエスケープする。
- `src/main.ts`：操作と状態管理。動的な表示には `textContent` と `t()` を使う。
- `src/ui/candidates.ts`：候補表の更新。
- `src/model/worker.ts` / `loader.ts`：AI進捗・エラーも同じ文言ファイルを参照する。
- `vite.config.ts`：ブラウザタブの初期タイトルも同じ文言から生成する。

項目名の誤り・削除はTypeScriptの型検査で検出します。新しい文言を追加するときも、コードに直接文章を書かずJSONに項目を追加してください。
