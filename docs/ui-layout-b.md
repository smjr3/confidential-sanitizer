# UI案Bの反映

## 変更

- 入力／候補／出力の3カラム構成。ページの縦スクロールをなくし、文章・候補一覧は枠内でスクロールする。
- 中央の幅を抑え、置換先108px・種別79pxを基準に、残りを元の文字列へ割り当てる。検出方法・信頼度は元の文字列の下に表示する。
- 左は入力・編集とハイライト確認を切り替える。チェックすると確認表示に切り替える。ページをスクロールする処理は追加しない。
- 入力クリアを左上に常設。コピー／TXTボタンは幅112px以上。
- 右上の使い方ダイアログ。閉じるボタン・外側クリック・Escに対応。
- 種別メニューの外側クリック・Esc・フォーカス移動で閉じる。
- 同一サイトからfavicon.svgを配信。ローカルの配布物用サーバーにもSVGの配信形式を追加。

## 既存機能の確認

入力クリア、ルール検出、AI結果の取込・信頼度、再チェック時の編集保持、検出箇所のハイライト、手動追加、種別の日本語表示、種別による対象絞り込み、全種別の選択／解除、候補単位の解除、置換先・種別の編集、合計、一覧コピー／CSV、結果コピー／TXT、コピー通知、マスキング0件の注意表示、AIの進捗・エラー表示・入力変更による中断を保持した。

## 検証

- 単体・画面処理テスト54件成功。新規に表示タブ、クリア後の状態、メニューの閉じ方、使い方ダイアログ、コンパクト表での信頼度・種別編集を確認。
- TypeScriptの型検査・Viteの本番ビルド成功。
- 生成したindex.htmlのfavicon参照は `./favicon.svg`。同じdistフォルダへSVGがコピーされることを確認。
- npm依存、検出・マスキングの計算処理、モデルの配布・ロード方針は変更していない。
- テストはhappy-domで画面構造とイベントを再現したもの。実ブラウザでのレイアウト計測、Windows実機、実モデルの推論は今回未検証。幅1100px未満では作業領域内の横スクロールを許可し、操作部品を隠さない。
